## 📌 Overview

An interactive **Power BI dashboard** developed to analyze hospital emergency room performance, patient trends, and operational efficiency. The dashboard transforms healthcare data into meaningful visual insights to support data-driven decision-making.

## 🎯 Project Objectives

- Monitor emergency room performance.
- Analyze patient visits and monthly trends.
- Identify patterns that may affect hospital operations.
- Present healthcare data through interactive visualizations.
- Support evidence-based operational decisions.

## 📈 Key Features

- 📌 KPI cards for essential performance indicators
- 📊 Interactive charts and graphs
- 🎛️ Filters and slicers for data exploration
- 📅 Time-based analysis
- 👥 Patient trend analysis
- 💡 Data-driven recommendations

## 🚀 Getting Started

### Option 1: Explore on GitHub

1. Browse the dashboard screenshots above.
2. Review the project documentation.
3. Download the `.pbix` file if available.

### Option 2: Open in Power BI Desktop

1. Clone or download this repository.
2. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` file.
4. Refresh the data source if required.
5. Explore the report pages, filters, and visualizations.
